# Project Scope

## Included
- Standard laptop request processing.
- ServiceNow-based request workflow.
- Flow Designer configuration.
- Request validation and workflow conditions.
- Approval handling where required.
- Fulfilment task creation or update.
- Request status progression.
- Testing of the configured workflow.
- Documentation and screenshots of the implementation.

## Not Included
- Procurement of non-standard or specialized hardware.
- Actual payment or financial transactions.
- Physical delivery management outside the configured workflow.
- Integration with external vendor systems unless separately configured.
- Enterprise-wide deployment beyond the project environment.

## Users
The workflow is intended to support employees requesting a standard laptop and the IT/procurement personnel responsible for processing the request.
