# Proposed System

The proposed system uses ServiceNow Flow Designer to automate the standard laptop request process.

### Proposed Workflow
1. A user submits a standard laptop request.
2. The configured flow is triggered.
3. The flow evaluates the request information and configured conditions.
4. Approval is requested when required.
5. After approval, the workflow creates or updates fulfilment activities.
6. The request progresses through the defined stages.
7. Status information is updated.
8. The request is completed after the required fulfilment activities are finished.

### Benefits
- Less repetitive manual work.
- Consistent processing.
- Faster movement between workflow steps.
- Better tracking of request status.
- Reduced risk of manual errors.
- Clearer separation of request and fulfilment activities.
