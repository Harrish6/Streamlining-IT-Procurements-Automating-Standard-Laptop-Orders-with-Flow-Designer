# Modules

## 1. Laptop Request Module
Allows a user to submit a request for a standard laptop.

## 2. Request Validation Module
Checks the information associated with the request according to the configured project conditions.

## 3. Approval Module
Handles approval activities when approval is required for the request.

## 4. Fulfilment Module
Creates or updates the activities required to fulfil the laptop request.

## 5. Status Management Module
Updates the request as it moves through the workflow.

## 6. Testing Module
Verifies that the flow behaves correctly for the configured scenarios.
