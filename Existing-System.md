# Existing System

In a manual or less automated process, a laptop request may pass through several activities performed by different people.

### Typical Manual Process
1. Employee submits a laptop requirement.
2. IT personnel review the request.
3. Request details are checked manually.
4. Approval is requested.
5. The request is assigned for fulfilment.
6. Procurement or IT personnel process the order.
7. The request status is updated manually.
8. The request is closed after completion.

### Limitations
- Repetitive manual work.
- Possible delays between processing steps.
- Greater dependence on human intervention.
- Possibility of inconsistent status updates.
- Difficulty maintaining a standardized process.
- Limited automation of routine actions.
