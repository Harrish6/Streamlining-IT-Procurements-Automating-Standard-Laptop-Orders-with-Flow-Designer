# Technologies Used

## ServiceNow
ServiceNow is the platform used for the project implementation. It provides the environment for handling IT service requests and automating business processes.

## Flow Designer
Flow Designer is used to design and automate the laptop procurement workflow. It allows triggers, conditions, actions, approvals, and other workflow steps to be connected into a structured process.

## Service Catalog / Request Management
The project uses the ServiceNow request concept to represent the user's requirement for a standard laptop.

## GitHub
GitHub is used to store and organize the project source documentation, report, screenshots, and presentation materials.
