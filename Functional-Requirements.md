# Functional Requirements

1. The system shall allow a user to submit a standard laptop request.
2. The system shall trigger the configured flow when the defined request condition is met.
3. The system shall evaluate configured conditions.
4. The system shall support approval handling where required.
5. The system shall create or update fulfilment activities according to the flow design.
6. The system shall update request information as workflow stages are completed.
7. The system shall allow the team to verify the workflow through test requests.
8. The system shall maintain a clear workflow sequence from request submission to completion.
