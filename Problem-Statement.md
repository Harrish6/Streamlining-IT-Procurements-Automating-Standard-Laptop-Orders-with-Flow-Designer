# Problem Statement

IT departments receive requests from employees for standard laptops and other equipment. Processing these requests manually may require several steps, including checking request details, obtaining approval, assigning fulfilment work, updating statuses, and completing the request.

When these steps are performed manually, the process can become repetitive and time-consuming. There may also be delays, inconsistent processing, or mistakes in updating request information.

Therefore, there is a need for an automated workflow that can process standard laptop requests in a consistent and structured manner. This project addresses the problem by using ServiceNow Flow Designer to automate the standard laptop ordering process.
