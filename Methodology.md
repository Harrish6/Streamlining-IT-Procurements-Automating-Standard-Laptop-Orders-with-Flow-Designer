# Methodology

## Phase 1: Requirement Analysis
The project requirements were identified by studying the standard laptop procurement process and determining which repetitive activities could be automated.

## Phase 2: ServiceNow Setup
A ServiceNow project environment was used to configure the required request and workflow components.

## Phase 3: Flow Design
The laptop ordering process was converted into a sequence of automated workflow steps using Flow Designer.

## Phase 4: Conditions and Actions
Conditions were defined to control the flow based on request information. Actions were configured for approval, fulfilment, task handling, and status progression according to the project design.

## Phase 5: Testing
Test requests were submitted to verify that the flow was triggered correctly and that the configured actions occurred in the expected order.

## Phase 6: Documentation
Screenshots and project documentation were prepared to demonstrate the implementation and results.
